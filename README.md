# REENTRY – web

Web spolku **REENTRY – Institut podmíněného propuštění, z. s.** (IČO 300 33 411).

- `index.html` – veřejný web
- `checklist.html` + `checklist-data.js` – checklist týmu do spuštění programu (sdílený přes Firebase)
- `reentry-crm.html` – ukázková verze CRM (bez skutečných dat klientů)
- `ochrana-osobnich-udaju.html` – ochrana osobních údajů
- `img/` – logo a ilustrace

Nový bod do checklistu: přidej řádek do `checklist-data.js`, nebo ho přidej přímo na stránce.
